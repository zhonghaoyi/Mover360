# 360mover environment for CUDA 12.8 / NVIDIA Blackwell (sm_120)
# Recommended for a fresh Python 3.12 environment on this machine.
#
# Why nightly torch?
# - Stable torch 2.7.0+cu128 pulls nvidia-nccl-cu12==2.26.2
# - That stack reproduced multi-GPU NCCL illegal memory access on RTX PRO 6000 Blackwell
# - Use the PyTorch nightly cu128 wheels and let torch resolve the matching CUDA/NCCL/Triton runtime
#
# Typical install:
#   python -m pip install -U pip setuptools wheel
#   python -m pip install -r requirements_cuda128.txt
#
# Notes:
# - Do not manually pin nvidia-nccl-cu12 here.
# - Do not manually pin triton here.
# - diffusers is installed from a pinned git commit for Flux2 support.
