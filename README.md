# Mover360: Controllable Object Manipulation in 360° Panoramic Images

**Project page:** https://zhonghaoyi.github.io/Mover360/

Interactive results for **Mover360** — point-, bbox-, and mask-guided object
**translation**, **insertion**, and **removal**, performed natively on
equirectangular 360° panoramas.

Paper, code, and dataset links will be added upon release.

<sub>360° viewer: [Pannellum](https://pannellum.org/) (MIT)</sub>
